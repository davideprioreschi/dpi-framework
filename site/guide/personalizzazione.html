Variabili CSS

Token del sistema: si ridefiniscono, non si sovrascrivono le classi.

Ogni valore visivo è una custom property --dpi-* (elenco generato da tokens.css qui sotto). Si personalizza ridefinendole su un selettore (pagina o contenitore):

.cliente-acme { --dpi-accent: #7a2bd1; --dpi-radius-md: 4px; --dpi-focus-width: 3px; }
