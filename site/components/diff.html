diff

Differenze di codice (o codice con numeri di riga) con righe aggiunte e rimosse distinguibili e selezione di righe dal numero.

Esempi

Diff con selezione di righe

src/saluto.js
@@ -1,3 +1,4 @@
function saluta(nome) {
Rimossa - return "Ciao " + nome;
Aggiunta + const testo = `Ciao ${nome}`;
Aggiunta + return testo;
}

Pannello dell'applicazione: appare sotto l'ultima riga selezionata.

<div class="dpi-diff" data-dpi-diff role="group" aria-label="...">
  <div class="dpi-diff__row dpi-diff__row--file"><code class="dpi-diff__text">src/saluto.js</code></div>
  <div class="dpi-diff__row dpi-diff__row--hunk"><code class="dpi-diff__text">@@ -1,3 +1,4 @@</code></div>
  <div class="dpi-diff__row dpi-diff__row--add" data-dpi-diff-line="2" data-dpi-diff-path="src/saluto.js">
    <button class="dpi-diff__num" type="button" data-dpi-diff-pick aria-pressed="false" aria-label="Riga 2">2</button>
    <span class="dpi-diff__sign"><span class="dpi-visually-hidden">Aggiunta </span><span aria-hidden="true">+</span></span>
    <code class="dpi-diff__text">  const testo = ...;</code>
  </div>
  <div class="dpi-diff__row dpi-diff__row--del"> ... </div>   <!-- riga rimossa: numero non selezionabile -->
  <div class="dpi-diff__panel" data-dpi-diff-panel hidden> ... </div>
</div>

Classi e attributi

NomeTipoUso
dpi-diffclasseContenitore (con data-dpi-diff). Modificatore dpi-diff--plain: nasconde la colonna dei segni (codice con numeri di riga).
dpi-diff__row--add / --del / --ctxclasseRiga aggiunta (superficie success), rimossa (superficie danger), di contesto.

Comportamento: tastiera, eventi e stati

Il clic sul numero di una riga la seleziona (aria-pressed sul pulsante e dpi-diff__row--selected sulla riga); un secondo clic sulla stessa riga deseleziona; Maiusc+clic seleziona l'intervallo dalla riga di partenza, nello stesso file; Esc deseleziona. Tab raggiunge i numeri, Invio/Spazio li attiva. Evento dpi:diff-select (bubbling) con detail { diff, path, from, to, panel } (from = 0 a selezione vuota). API: DPI.diff.select(diff, path, da, a), DPI.diff.clear(diff), DPI.diff.selection(diff). Il pannello [data-dpi-diff-panel] viene spostato sotto l'ultima riga selezionata senza ricrearne il contenuto.

Parti incomplete

Il framework non legge i patch né evidenzia la sintassi: il markup delle righe lo costruisce l'applicazione (con escape del testo). Le righe rimosse non hanno numero selezionabile. Non verificato in un browser dall'agente; Firefox e WebKit mai provati.
