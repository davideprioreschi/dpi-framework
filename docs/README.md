# Componenti

[README](../README.md) · [Guida](guida.md) · [Documentazione interattiva](https://davideprioreschi.github.io/dpi-framework/site/components.html)

Ogni pagina raccoglie un componente o una famiglia. La colonna «Pagine del sito» elenca le voci della documentazione interattiva coperte: le voci che sono «parte di» un altro componente (per esempio `accordion_item` o `tab`) stanno nella pagina del componente padre.
